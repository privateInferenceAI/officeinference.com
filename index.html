Which one fits

Standard Cloud works well if you have a non-regulated business, want to use current frontier models, and want to get up and running quickly while your cloud provider bills you for usage.

Compliant Cloud works well if you have a regulated or government business and need to satisfy compliance rules. You can use current frontier models, start quickly, and pay your cloud provider for usage. We scope the compliance work and document the evidence.

In-Office works well if you want your data never to physically leave your building. It's also very good for satisfying compliance rules, or any stricter company rules. You can use current open weight / open source models. The startup is the hardware, and there are no per token costs. You do pay for power, cooling, and maintenance, and service contracts are optional depending on your company's technical expertise. An entry system starts around $30,000 in hardware. A model in the same class as the cloud's frontier models starts around $400,000 and needs a server room.

If you're not sure, email us. We'll help you find the option that fits or answer any questions you might have.

What In-Office costs

Most of the cost is the model. A current open model at full precision, running on one workstation, starts around $30,000 in hardware. That model is good, but it is not a frontier model, and the answers show it.

A local model in the same class as the cloud's frontier models needs a server room and about $400,000 in hardware. The current top open-weight model, at full precision, is a data-center machine: six servers, 48 GPUs, and more than $2 million.

There are no per-token fees at any size. Power, cooling, backups, updates, and an optional support contract are real monthly costs. On an entry system, power runs a few hundred dollars a month. A support contract, if you want one, is quoted with the system.

That is why we offer both. Use the cloud when your documents are allowed to leave. Use In-Office when they are not, and budget for the hardware the job actually needs.

How it works

It's not magic, it's more like a layered cake. One layer reads your documents and indexes them. One layer decides which AI model answers what, and logs it. One layer is the chat you actually see. One layer does the grunt work: email drafts, approval routing, reminders. Standard Cloud lives in your cloud account and runs commercial models. Compliant Cloud also lives in your cloud account, runs commercial models on compliance-grade services, and is built for regulated work under signed agreements. In-Office lives in your building, runs open weight / open source models, and can also satisfy compliance rules.

Start where you are. Move when the rules change.

You can start with any service. Standard Cloud is the most economical in the beginning. Compliant Cloud is where regulated work usually starts, because it runs on your provider's compliance-grade services under signed agreements. In-Office is where clients end up when they want the data physically incapable of leaving, or the system has to keep working without an internet connection. All three run basically the same system, so moving is a deployment change, not a rebuild.
