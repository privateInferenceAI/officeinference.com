AI that answers questions about your business documents.

Run it in your building when privacy demands it. Run it in the cloud when it doesn't. Same system either way.

Office Inference Private

Everything inside your building.

The models, the document store, the chat interface, and the automation all run on a server in your office. Nothing you type or upload touches the internet. For medical practices, law firms, and anyone whose data rules are not negotiable.

Office Inference Cloud

Same system, commercial brain.

Same gateway, same document pipeline, same controls. The language model is a commercial one, reached through Amazon Bedrock or a model API. Lower cost and faster setup, and your files still live on infrastructure dedicated to you. For businesses without strict data rules.

You pay per question, forever. When the monthly bill starts to look like a hardware payment, that's the signal to move to Private.

Start where you are. Move when the rules change.

Plenty of businesses start on Cloud because it's cheap and fast. When a client contract or a regulator says your data has to stay in the building, you move to Private. Both tiers run the same system, so the move is a configuration change. It is not a rebuild.

Who it's for

Small businesses whose client data has rules. Medical practices that can't risk patient records. Law firms whose client files are privileged. If your staff is pasting sensitive documents into public chatbots today, you have the problem we solve.

How it works

Every system has four parts. A chat interface your staff already knows how to use. A gateway that decides which model answers which question and logs every request. A document pipeline that reads your files and makes them searchable. An automation layer that drafts emails and routes approvals. In Private, all four run on your hardware. In Cloud, the first three run on dedicated infrastructure and the model is commercial.
