# officeinference.com

This repository is the source for officeinference.com, the marketing site for Office Inference. It is a static multi-page site (index.html, about.html, contact.html, and a branded 404.html) built from plain HTML and one shared styles.css, with no JavaScript, no webfonts, and no build step, served by GitHub Pages from the root of the main branch of privateInferenceAI/officeinference.com. The CNAME file in this repo tells GitHub Pages to answer for the custom domain officeinference.com; the DNS records that point the domain at GitHub Pages live at the registrar and are managed separately, outside this repo. sitemap.xml and robots.txt cover the three pages. The contact form on contact.html posts to Formspree (free tier); submissions are delivered to the site owner's inbox, and a hidden _subject field tags them as coming from the website.
