# officeinference.com

This repository is the source for officeinference.com, the one-page marketing site for Office Inference. It is a static site (index.html plus styles.css, no JavaScript and no build step) served by GitHub Pages from the root of the main branch of privateInferenceAI/officeinference.com. The CNAME file in this repo tells GitHub Pages to answer for the custom domain officeinference.com; the DNS records that point the domain at GitHub Pages live at the registrar and are managed separately, outside this repo.
